# Advanced Todo List (Python)

## Features
- Add Tasks
- Remove Tasks
- Search Tasks
- Mark Tasks Completed
- Task Priority System
- Pending & Completed Reports
- Menu Driven Program

---

## Technologies Used
- Python
- Lists
- Nested Lists
- Loops
- Conditional Statements

---

## Task Structure

Each task is stored like this:

[
    "Task Name",
    "Priority",
    "Status"
]

Example:

[
    "Learn Python",
    "High",
    "Pending"
]

---

## How To Run

1. Install Python
2. Save file as:

todo.py

3. Run command:

python todo.py

---

## Example Menu

1. Add Task
2. View Tasks
3. Mark Task Completed
4. Remove Task
5. Search Task
6. Total Tasks
7. Exit
